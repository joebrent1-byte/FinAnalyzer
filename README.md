# FinAnalyzer

A React Native Expo app for stock data, portfolio tracking, ratio analysis, and financial screening.

## Features

- Dashboard with key market metrics and price chart
- Search and screen stocks using Yahoo Finance data
- Ratio analysis for valuation and risk metrics
- Portfolio tracking with positions and invested capital
- React Native UI designed for phones

## Tech stack

- Expo
- React Native
- TypeScript
- Zustand
- Axios
- react-native-chart-kit
- React Navigation

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Metro:
   ```bash
   npm start
   ```
3. Run on device or emulator:
   ```bash
   npm run android
   # or
   npm run ios
   ```

## Notes

This starter version is designed to be an MVP foundation. It includes Yahoo Finance API hooks and a clean app structure so you can expand into deeper modeling, watchlists, screening rules, and more advanced analytics.
