# FinAnalyzer

A mobile-first investment research app built with Expo and React Native.

## What it includes

- Dashboard with live market snapshot and price chart
- Search and watchlist management
- Ratio analysis screen for key financial metrics
- Portfolio tracking against current prices
- Yahoo Finance integration for quotes and price history

## MVP roadmap

1. Research overview dashboard
2. Watchlist and stock discovery
3. Core valuation metrics
4. Portfolio value tracking
5. Advanced screening and company detail views

## Tech stack

- React Native / Expo
- TypeScript
- Zustand for app state
- Axios for Yahoo Finance requests
- react-native-chart-kit for charts
- React Navigation for tab-based UX

## Run locally

```bash
npm install
npm start
```

Then run on Android or iOS via Expo Go or emulator.

## Product direction

This is designed as an investment research app rather than a simple stock ticker app, with an emphasis on watchlists, evaluation, and portfolio monitoring. The current MVP is intentionally lightweight and built to be extended with more advanced screening logic, company pages, and financial statements.
